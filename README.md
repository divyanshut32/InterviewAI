# InterviewAI

A polished React/Vite mock interview platform built for a Front-End Developer portfolio.

## Features

- Role and technology selection
- Fresher / Intermediate / Experienced levels
- Timed interview sessions
- Question progress indicator
- Answer submission and scoring
- Performance report
- Interview history using LocalStorage
- Dark/light mode
- Responsive mobile-first UI
- Mock question banks for JavaScript, React, Java and Python

## Run locally

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Build

```bash
npm run build
```
